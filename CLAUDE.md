@AGENTS.md

`AGENTS.md` is the canonical development and gateway-maintenance instruction file for this repository.
Its **Working agreement** section applies to every session here: align on non-trivial work before
editing, verify through the full user journey and grade the evidence, finish with the full check set,
and never put host, credential, pairing or device data into this public repository.
For host installation/configuration, follow `docs/AGENT-SETUP.md` and `compatibility.json` instead of
performing app development or changing the gateway checkout.
