## 二、必须人工验的（adb 没法模拟真实语音）

### 2.1 语音主链路

1. 按住语音球 1 秒以上，说「你好，帮我看看服务器负载」，松手。
   - 期望：球变深色 → 「正在听…」→ 松手后「正在识别…」→ 自动进入新建的会话，输入框里能看到识别文本。
2. 说一句纯噪音（或者不说话就松手）。
   - 期望：弹出「没听清」，**不新建会话**。
3. 按住不到 0.4 秒就松手。
   - 期望：什么都不发生（不当成一次录音）。

### 2.2 卡片按住直回

需要先让某个会话处于「待审批」：

1. 在会话里让 agent 执行一条会触发审批的命令（例如写工作区外的文件）。
2. 回首页，卡片应变成「待审批」样式（暖砂色边框）。
3. 按住这张卡 0.6 秒，说「可以」，松手。
   - 期望：审批被批准，卡片消失或变成进行中。
4. 同样的场景说「不可以」。
   - 期望：审批被拒绝。
5. 说一句无关的话（「今天天气怎么样」）。
   - 期望：**什么都不发**，弹「没听清」。这一条最重要——不能把胡话当消息塞进会话。
6. 制造两条同时待审批，再说「可以」。
   - 期望：不动手，提示进会话处理。

### 2.3 全部会话页交互

- 点组头折叠/展开（三角要转向）
- 搜索框输入「测试」，列表应按标题或目录过滤
- 长按任意一行 → 弹出会话菜单（重命名/分叉/归档）
- 归档一个会话 → 底部出现「已归档 N 个 · 显示」，展开后能看到它

### 2.4 视觉细节（对照 docs 里的设计稿）

- 卡片两列时右边不出屏、不重叠
- 字号放大到系统 1.3× 后卡片不裁切
- 深色模式下这几个新页面（`eink_slate`）颜色是否正常

## 六、2026-10-29 下午的补充

- **聚焦网格改为常驻**：不再「agent 答完卡片就消失」。现在固定展示最近 4 个会话，
  排序是「待审批 > 进行中 > 刚聊过」，所以轮到你回话的永远在最前面。
- **转盘抢滚动已修**：转盘展开时给消息列表设 `scrollEnabled={!dialOpen}`，
  手指在转盘上滑不会再带着底下的轮次一起滚。adb 实测：展开后上下拖 500ms 仍能切会话。
- **语音在哪识别**：手机只录音（16k 单声道 PCM16 WAV → base64），识别在服务器
  （sensevoice-local / SenseVoiceSmall INT8，模型约 1 GB，实测 1 秒音频推理 12 ms）。
  界面文案已从「正在识别…」改为「服务端识别中…」。
