# DSH Mobile 使用说明

DSH Mobile 是 DeepSeek Harness（DSH）的手机客户端。它不在手机上运行 agent，而是通过
`dsh-plugin-mobile-gateway` 插件连接一台正在运行的 DSH 宿主。

这份说明按真实使用顺序覆盖：配对、日常使用、审批、附件、语音、多网关、可选地址簿、离线行为与故障排查。

> App 仍是实验性版本，与 DeepSeek、Expo 官方无关。请搭配兼容的网关版本使用。

## 1. 开始之前

你需要：

- 一台运行 DSH Web 的机器。
- 在运行 Web 的 DSH profile 里安装 `dsh-plugin-mobile-gateway`。
- 手机到网关的网络路径：
  - 同一 Wi-Fi（局域网直连），或
  - Cloudflare Quick Tunnel / 命名 Tunnel，或
  - 其他可达入口（例如 Tailscale）。
- 手机上已安装 DSH Mobile。

网关面板是连接状态、已配对设备和可选地址簿的唯一事实来源。

## 2. 配对

### 2.1 安装并启用网关插件

最简单的方式是在 DSH 宿主上、从本仓库打开一个普通终端（不是 DSH Web 的聊天），运行：

```bash
node scripts/setup-gateway.mjs install --yes --stop-web --restart-web \
  --tunnel quick --pair --open
```

它会停掉 DSH Web、安装固定 release、可选安装语音、在后台重启 DSH Web、启用网关、开 Quick Tunnel，
并打开配对二维码页。DSH Web 重启期间聊天界面会消失；重启后原会话仍在列表里，重新打开即可。

加 `--voice` 安装与 DSH `0.2.1-rc.5` 匹配的语音 bundle 并预下载约 241 MB 的 SenseVoice 模型；
`--no-voice` 跳过。以后要加语音，停掉 DSH Web 后运行 `node scripts/setup-gateway.mjs voice`。模型 ready
之前 App 会显示「语音未启用」；不要在 `0.2.1-rc.5` 上装旧的 `0.1.7-alpha.1`。

手动方式：先停掉 DSH Web（往运行中的 Web 进程里装 bundle 会热重载插件树，可能让 `sessionController`
一直不可用，直到整个进程重启），再运行 `node scripts/setup-gateway.mjs install --yes`：

```bash
# Linux systemd
sudo systemctl stop dsh-web
# 或者 Ctrl+C 掉正在运行 `dsh web` 的终端

node scripts/setup-gateway.mjs install --yes
```

脚本会安装固定 release，并在 3080 被监听时拒绝（除非显式传 `--stop-web`）。不要用 `@latest`；上游是
另一条 release 线，不在本 App 版本的验证组合内。详见 [COMPATIBILITY.md](COMPATIBILITY.md)。

启动 DSH Web，然后启用网关：

```bash
node scripts/setup-gateway.mjs enable
```

打开 DSH Web → **移动设备 → 连接与配对**，或运行 `node scripts/setup-gateway.mjs pair --open`，
再选择手机访问方式。第一次在同一 Wi-Fi 下测试时，局域网直连最短；要在局域网外使用，就启用隧道并等
公网地址就绪。

如果 Web UI 说 Quick Tunnel 公网入口未通过验证、但隧道日志显示 online，可能是宿主本机 DNS 被污染，
隧道本身仍然可用。用 `pair` 生成配对页；如果手机也解析不了域名，就在手机上开 VPN 或 Private DNS
（DoH），或者改用 Tailscale / 命名 Tunnel。

### 2.2 生成配对码

在同一个面板点击生成配对。面板会显示二维码和配对载荷。如果宿主提供 `dsh-pair`，
也可以在终端打印同样的载荷；默认五分钟内有效。

配对载荷包含一次性设备 token。不要截图或分享仍然有效的二维码。

### 2.3 扫码或粘贴

1. 打开 DSH Mobile。
2. 点 **扫码配对**。
3. 按系统提示允许相机权限。
4. 对准二维码。

相机不可用或权限被拒绝时，点 **手动粘贴配对串**，粘贴文本后点 **配对并连接**。

配对码只能使用一次，约五分钟后过期；过期后请在宿主上重新生成。只有 App 收到长期设备 token 后配对才算成功，
token 会存进手机的安全存储。

### 2.4 添加更多设备或网关

- 每台手机单独配对。撤销一台手机不会影响其他手机。
- 添加网关：点首页顶部的网关名 → **＋ 添加网关**，然后扫码或粘贴。
- 切换网关：在同一个菜单点已保存的网关。每个网关各自保存会话列表、工作区选择、草稿和发件箱。
- 从手机移除网关：菜单 → **移除当前网关**。这只删除本地记录和 token，**不会**在服务端撤销设备。
  要真正让 token 失效，请到网关面板撤销设备。

## 3. 首页

底部有四个 Tab：

| Tab | 用途 |
| --- | --- |
| **聚焦** | 正在运行、正在等你处理的事项 |
| **全部会话** | 全部会话，按工作区分组 |
| **定时任务** | agent 创建的定时任务 |
| **插件** | 网关侧的插件管理 |

### 3.1 聚焦

聚焦页最多显示四个最近会话，按「需要你出手」排序：有待处理审批/提问的最前，其次是运行中的，
最后是最近聊过的。卡片显示标题、目录、最后一句回复摘要，以及待办或未发送消息的角标。

- **点按**卡片打开会话。
- **长按**卡片可以直接语音回复这个会话：按住说话，松开发送。
- 网格上方的工作区选择只影响**之后新建**的会话，不会移动已有会话。可以选择已注册工作区、
  网关默认目录，或在宿主 home 下新建一个 `mobile` 工作区。
- 下面的语音球用于**新会话**消息：按住说话，松开发送；按住时上滑取消。
- 双击宠物会新建会话；横向滑动可以把它移到一边。
- 语音不可用时，语音球会明确提示，不会静默失败。

### 3.2 全部会话

- 搜索框会过滤会话。
- 会话按工作区分组；归档会话默认隐藏，底部的归档行可以显示/隐藏。
- 角标表示草稿、排队消息或待处理事项。
- 点会话进入对话页。条目菜单提供 **重命名**、**归档/取消归档**、**从最近一轮分叉**。
- 打开会话后会清除未读标记。

### 3.3 定时任务

目录由 agent 通过 DSH 的定时任务工具创建，手机端主要是只读视图。打开一条可以看到计划、提示词、状态和
运行历史。根据网关支持情况，可以重命名或删除；删除定时任务不会撤回已经投递的消息。

### 3.4 插件

这里管理的是**网关背后的 DSH profile** 里的插件，不是手机 App 自己的插件。可以查看网关能力位、
浏览插件目录、安装 bundle、编辑设置、启停和卸载。

两点注意：

- 关闭或卸载 `dsh-plugin-mobile-gateway` 本身会立刻切断手机连接，只能从宿主的 DSH Web 或 CLI 恢复。
  App 会把这类操作标成「待重连确认」，不会当作成功或失败。
- 安装插件时可能需要批准特定包的原生构建。请先看清包名，不要批准不认识的构建。

## 4. 会话页

### 4.1 流式输出与轨迹

回复会流式进入对话。思考块、工具调用和工具输出会折叠成一组；点一下展开。回合结束时，如果你本来就在底部，
最后一条用户消息会被锚定到视口上方，正文随后展开，不需要追着滚动。

流式输出期间可以自由向上翻；只有你在底部时，App 才会跟随新输出。

### 4.2 阅读与复制

- 长按文本可以选择并打开选择面板。
- 代码块和工具输出可以复制；代码块还可以引用到输入框。
- Markdown 支持标题、列表、表格、链接和围栏代码。过长的工具输出会被网关截断并标注。

### 4.3 模型、权限与 agent 预设

输入框上方会显示当前模型、权限模式，以及（网关支持时）会话的 agent 预设。可以在那里切换。

- 可用模型和权限模式来自宿主，App 不会凭空造选项。
- agent 预设通常在会话跑过第一轮后**锁定**，标签上会显示锁定状态。想换预设请新建会话。
- 权限越高，agent 越少询问。请使用能完成任务的最低权限。

### 4.4 命令、任务与目标

- 在输入框输入 `/` 打开命令面板。命令由宿主提供，取决于会话和网关版本。
- **任务**标签显示当前会话已完成/总任务数；点开就是任务面板。
- 有目标时会显示**目标**标签，打开后可以暂停、继续或清除目标。写操作会带上次读到的 revision；
  如果另一个客户端改过，App 会先刷新而不是覆盖。
- **轮次**标签打开轮次大纲，点某一轮可以跳过去。

### 4.5 agent 运行中发送

agent 正在跑时，输入框提供两种模式：

- **排队**：等当前回合结束后发送。
- **插话**：插入当前回合，在下一步模型调用时生效。

排队消息显示在输入框上方。开始执行前可以编辑或撤回。输入框为空且回合正在跑时，主按钮会变成停止键；
点它取消当前回合。

### 4.6 消息投递状态

每条发出的消息都有状态：

- **发送中**：等待网关回执。
- **排队中**：已接受，等后续回合，或排在前面的排队消息之后。
- **未确认**：回执到达前连接断了。App 不会静默重发；请重试或移除。
- **失败**：网关拒收或无法投递。可以在消息菜单重试、重新编辑或移除。

离线时发送的文字会进入发件箱，重连后按顺序发送。带附件的消息不能离线发送：上传绑定在创建它的连接上。

## 5. 审批与提问

DSH 可能在工具调用前要求人工审批，或让 agent 提出问题。两者会出现在对话里，也会计入聚焦角标。

### 5.1 审批

审批卡会展示请求内容：命令或工具、目标文件、可用时的 diff、原因和风险标签。请读真实命令，不要只看摘要。

- **允许 / 拒绝**会把决定发给网关。
- 高危审批的「快速允许」会变成**按住约半秒**的按钮，填充进度和震动会确认你按住了。
- 拍板后会出现几秒的撤回胶囊。倒计时结束才真正发送决定；在此之前可以点撤回。
  如果倒计时期间离开页面或 App 进入后台，决定会被发送而不是丢失。
- 如果网关已经没有这条审批（被撤回或别处处理），App 会明确提示，不会假装成功。

审批不能离线决定。App 会保留卡片，重连后请你重新拍板。

### 5.2 提问

提问卡会显示 agent 的问题和选项。可以选择一个选项，或输入回答。**跳过**会给 agent 发送取消，
不记录任何答案；不想让 agent 按这个问题继续时使用它。

### 5.3 离开期间产生的审批

审批会留在网关，打开会话或刷新聚焦页时仍能看到。App 不会自动批准任何东西。聚焦页的语音回复也不会
替你拍板：如果目标会话有待处理项，App 会打开会话并高亮那一项，让你在卡片上决定。

## 6. 附件

点输入框的 **+**，选择：

- **拍照**：打开相机。
- **从相册选择**：打开相册。
- **文件**：打开系统文件选择器。

### 6.1 图片

- 图片限制由网关下发。默认单张 20 MB、单条消息总计 200 MB；单条消息的图片数量上限也由网关决定。
- 需要时会压缩和缩放；App 会按压缩后的实际字节再检查一次。
- 图片会和文字一起挂到消息上发送。

### 6.2 文件

文件走网关的 `file-upload-v1`：open → chunk → finish，拿到 upload receipt 后再挂到消息上。

- App 本地限制每个文件 24 MB。网关可能允许更大文件，但手机要把整份文件读进内存再上传，24 MB 是安全上限。
- 上传时会计算并提交 SHA-256。
- 文件上传完成后消息才会发送；上传失败不会带着坏附件发出去。
- 必须在线。离线消息不能携带文件。

### 6.3 下载文件

消息里有文件卡时，点一下会下载并打开。下载按 offset 续传并缓存在本地。网关关闭文件下载能力时，
App 不会画一个点了没反应的按钮。

## 7. 语音输入

只有网关暴露 `speech-input-v1` **并且**有就绪的语音 provider 时，语音入口才可用。
「语音未启用」表示没有 ready 的 provider——例如模型还没下载完——不代表网关关闭了语音能力。

### 7.1 在会话页

- 按住麦克风按钮说话，松开后转写结果作为消息发送。
- 按住时上滑取消录音。
- 录到 provider 上限会自动停止，转写文字放回输入框而不是代发半句话。改完再发。
- 一次按住正在转写时，界面会显示状态；等它结束再按下一次。
- 太短的轻点会被忽略并提示，避免误发空消息。

### 7.2 在聚焦页

- **按住语音球**开始一条新会话消息，松开发送。
- **长按聚焦卡片**给那个会话语音回复。
- 按住时上滑取消，录音上限同理。
- 语音结果不会替你批准或回答待处理项。App 会帮你打开那一项。

语音音频会发给宿主配置的语音 provider。手机本地不做语音识别。

## 8. 多网关与地址变化

### 8.1 多网关

每个已保存网关各自拥有：

- 设备 token 和网关身份，
- 会话列表缓存，
- 工作区选择，
- 草稿和发件箱。

切换网关时，App 会先清掉上一个网关的内存会话状态，再连接新网关。排队消息只会发给它所属的网关。

### 8.2 网关地址变化

Quick Tunnel 重启或宿主换网络后，隧道 URL 或局域网 IP 可能变化。

- 如果 App 还连着，网关推送配置变化时，App 会自动采纳新地址。
- 如果 App 已经连不上，没有地址簿时需要重新生成二维码并配对。
- 启用可选地址簿后，App 会从 Worker 取回最新加密地址并重试，不需要重新扫码。

`gatewayId` 变化和地址变化不是一回事。App 会把不同的网关身份当作冲突并要求重新扫码，不会静默连到另一个网关。

## 9. 地址簿（可选）

地址簿只解决一个问题：已经配对过，但网关公网地址变了，不想回到宿主重新扫码。

### 9.1 在网关侧启用

1. 打开 DSH Web → **移动设备 → 连接与配对 → 地址簿 · 免重扫**。
2. 点 **启用地址簿**。
3. 按提示完成 Cloudflare 设备登录：打开打印出的地址或扫登录二维码，授权账号。免费账户即可。
4. 插件会部署 Worker，写密钥保存在宿主。面板会显示部署日志和最终 Worker 地址。

插件使用 `npx -y wrangler@<版本>`，不需要全局安装 `wrangler`。首次部署会下载 Wrangler，可能需要等一会儿。

### 9.2 手机获得什么

配对成功后，已认证连接会收到地址簿配置和一份设备密钥。网关用 AES-256-GCM 加密当前入口列表；
Worker 只保存密文。

App 连不上时，会查询 Worker，用设备密钥解密最新记录，再重试新地址。通常一到三分钟恢复，不是秒级切换。
App 在运行期间会持续重试。

一个 Worker 对应一个网关。如果多台机器都运行 DSH，请分别配对；每台网关可以使用自己的地址簿。
地址簿不会把多台宿主合并成一次配对。

### 9.3 停用、重新启用或使用已有 Worker

- **停用地址簿**会停止发布。面板提供「同时删除 Cloudflare 上的 Worker」选项；删除不可恢复。
  不删除时，宿主保留写密钥，重新启用可以复用同一地址。
- 重新启用且未删除 Worker 时，会复用保留的 Worker。
- 如果已经有 Worker，展开 **使用已有 Worker**，填入地址和写密钥后连接。手动配置与托管配置之间切换时，
  手机会在已认证连接上自动采纳新配置。

### 9.4 认证与隐私

- Worker URL 是公开的，但记录是加密的。Cloudflare 能看到请求元数据（路径、IP、时间、密文长度），
  看不到入口地址和设备密钥。
- 写密钥留在宿主；读取密钥只通过已认证连接下发给已配对设备。
- 撤销设备时，会删除它对应的地址簿记录。
- 如果所在网络打不开 `workers.dev`（中国大陆或某些 VPN/DNS 环境可能如此），可以改用自定义域名、
  命名 Tunnel 或 Tailscale。地址簿是可选的，核心 App 不依赖它。

## 10. 离线与重连

- 会话列表按网关缓存，断网冷启动仍会显示上次的列表；从未配对过的网关才会显示配对页。
- 草稿会保存到本地，离开会话不会丢弃输入内容。
- 离线时写的文字进入发件箱，重连后按顺序补发。断线时已经在途的消息可能显示**未确认**，需要手动重试。
- 文件上传和审批决定必须在线，不会进入队列。
- App 会自动重连。顶部提示连接断开时，点提示可以立即重试。进入后台后 JS 定时器会被系统挂起；
  回到前台时 App 会探活并在需要时重连。
- 设备 token 被撤销或过期后，自动重连会停止，并要求重新配对。

## 11. 安全与隐私

- 配对 token 和设备身份存放在 `expo-secure-store`。
- 公网入口必须使用 `wss://`。配对载荷里如果是公网明文 `ws://`，App 会拒绝，因为 token 会明文传输。
- 会话历史、草稿、附件元数据和下载文件会缓存在手机。手机解锁状态下，能拿到手机的人可以读到这些缓存。
- App 没有接入第三方分析 SDK。网关、DSH 宿主、Cloudflare 和 Expo 运行时仍可能保留各自的日志，请分别查看。
- 手机丢失时：到网关面板撤销该设备。在另一台手机上「移除网关」不会撤销丢失手机。

## 12. 限制

| 项目 | 限制 |
| --- | --- |
| 配对载荷 | 约 5 分钟，一次性 |
| 文件上传 | 每个文件 24 MB（App 本地限制） |
| 图片 | 单张 20 MB、单条消息 200 MB（网关默认值；数量也由网关决定） |
| 语音录音 | 由 provider 决定，常见约 2 分钟 |
| 离线带文件发送 | 不支持 |
| 地址簿恢复 | 通常 1–3 分钟 |
| 地址簿重试 | 取决于 Worker 和手机网络 |

## 13. 故障排查

### 二维码被拒绝 / 配对失败

- App 提示「网络或代理」时，先关闭手机上的 VPN/代理，再重试；App 会自动用同一个配对码
  重试一次。仍失败时检查 Wi-Fi/蜂窝网络，或把隧道域名设为直连。
- App 提示「配对码可能已被使用或过期」时才需要重新生成；一个配对码只能使用一次。
- 确认扫的是配对二维码，不是普通网址。
- 相机对不上焦时，改用手动粘贴。

### 连上后马上断开

- 确认宿主还在运行 `dsh web`，且网关已启用。
- Quick Tunnel 就绪可能需要几秒，等一会儿再试。
- VPN 或 DNS 代理可能破坏 `workers.dev` 或隧道域名，换一个网络试试。
- 点 App 里的连接提示立即重试；否则等待自动退避。

### 地址簿没有找回网关

- 确认网关面板显示地址簿已配置且发布成功。
- 最多等几分钟；恢复不是瞬时的。
- 用手机浏览器打开 Worker URL，确认可达。打不开就改用自定义域名或其他隧道。
- 如果网关身份变了（不只是地址变了），App 会提示冲突，需要重新扫码。

### 显示「语音未启用」

- 网关没有就绪的语音 provider。到宿主检查语音插件和模型下载状态。
- 能力可能存在，但模型还在 `unprepared`；App 要求有 ready/standby 的 provider。

### 消息报 `MISSING_CREDENTIAL`

宿主 DSH 没有找到模型 provider 的凭据，消息在调用模型前就失败了；不是手机或网关的问题。

- 在 DSH Web 的 Models 页面保存 provider key，或在 `~/.dsh/.credentials.yaml` 的 `refs:` 下写入
  对应环境变量（例如本地 magpie 的 `MAGPIE_GATEWAY_KEY`）。凭据文件默认会自动重载，不需要重启。
- 如果 key 只存在于启动命令的环境变量里，重启 DSH Web 时必须带上它；更稳妥的做法是存进凭据文件。

### 消息一直停在「未确认」

- 回执到达前连接断了。请从消息菜单重试，不要假设它已经送达。
- 离线时等重连后再重试。

### 附件失败

- 检查大小：文件 24 MB；图片默认单张 20 MB、单条消息 200 MB。
- 确认连接在线；离线带文件发送会被拒绝。
- 网关拒收上传时，检查网关的文件上传设置。

### 操作插件后连接断开

如果关闭或卸载了移动网关本身，手机按设计无法重连。从宿主的 DSH Web 或 CLI 恢复插件；
设备 token 失效时需要重新配对。

## 14. 移除 App 与撤销访问

1. 不再信任这台手机时，先在网关面板撤销它。
2. 在手机上从顶部网关菜单移除该网关，删除本地状态。
3. 卸载 App。
4. 如果启用了地址簿且不再需要，在网关侧停用。删除 Worker 是可选项，且不可恢复。
